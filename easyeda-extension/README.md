# 果子狸MCP服务

果子狸MCP服务是嘉立创 EDA / EasyEDA 专业版的本地 MCP 连接扩展。它与用户电脑上运行的开源 MCP 服务配合，让 AI 客户端能够通过结构化工具读取和编辑当前原理图。

## 功能

- 无需先打开图页即可列出当前工程中的全部原理图和图页。
- 读取器件、PIN、导线和网络。
- 创建、批量移动、旋转、删除器件及常用原理图图元。
- 创建导线、网络端口与网络标识。
- 根据 PIN 位于器件左、右、上、下哪一侧，沿 PIN 朝向创建端口，减少端口和器件重叠。
- 执行原理图 DRC，返回编辑器当前版本提供的检查结果。
- 在首次写入前自动备份当前原理图，同一 MCP 会话后续修改复用该备份。
- 通过悬浮框显示等待、已连接和已停止状态。

## 使用方法

1. 导入并启用本扩展。
2. 在电脑上安装 Node.js 20 或更高版本。
3. 从 `https://github.com/lyq11/guozili-mcp-service` 下载源码并运行 `npm install`。
4. 将仓库中的 `src/server.mjs` 配置为 AI 客户端的 stdio MCP 服务。
5. 刷新一次嘉立创 EDA 页面并打开原理图。
6. 通过“果子狸MCP服务”菜单打开状态悬浮框；显示“已连接”后即可调用 MCP 工具。

如果连接未建立，请确认 MCP 客户端已经启动服务，端口 `49620-49629` 未被防火墙阻止，并点击“重新连接”。扩展只连接 `127.0.0.1`，不会访问局域网或公网服务。

## 安全说明

本扩展不提供任意 JavaScript 执行能力。所有请求都必须通过令牌握手和固定 RPC 能力白名单。写操作会在 MCP 侧串行发送；一组编辑器 API 操作并非原子事务，操作失败时可以使用首次写入前生成的原理图备份恢复。
