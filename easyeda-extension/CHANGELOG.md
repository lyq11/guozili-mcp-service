# 更新日志

## 0.6.0 - 2026-07-21

- 新增物理叠层配置读取 RPC，并支持经过会话 PCB 备份的铜层数、内层名称和物理叠层覆写操作。
- 新建 PCB 可在导入原理图变更前应用叠层设置。
- 走线原地修改扩展到直线、圆弧和折线图元。

## 0.5.0 - 2026-07-21

- PCB 白名单操作新增独立板框创建，固定使用 Board Outline 层和空网络，支持直线及圆角圆弧。
- PCB 白名单操作新增走线、过孔原地修改，写入后核对原图元 ID，并返回修改前后属性。

## 0.4.0 - 2026-07-21

- 新增白名单 RPC `pcb.create`，使用 EasyEDA 原生文档树 API 创建 PCB、建立原理图关联并导入变更。

## 0.3.3 - 2026-07-21

- 新增经过白名单校验的独立 PCB 焊盘创建操作，覆盖贴片焊盘、圆孔焊盘和槽孔焊盘。
- PCB 快照新增独立焊盘列表。
- 修复器件焊盘被重复归入独立焊盘的问题；现在通过各器件 `getAllPins()` 返回的真实图元 ID 集合排除器件焊盘。

## 0.3.2 - 2026-07-21

- 新增经过白名单校验的 PCB 直线导线批量删除操作，并在保存后验证目标导线确已删除。

## 0.3.1 - 2026-07-21

- PCB 快照新增折线图元，并将 Board Outline 层折线归入板框缓存。
- 修复 PCB 局部区域检查的 Y 坐标方向校验。

## 0.3.0 - 2026-07-21

- 新增 `[main]` Board 范围校验和 PCB 列表、整板快照、局部区域、DRC 白名单 RPC。
- PCB 快照覆盖板框、层叠、封装、焊盘、网络、走线、过孔、铺铜、区域和设计规则。
- 新增器件变换、走线、过孔、铺铜、铺铜重建及从原理图导入变更的预检和写入 RPC。
- 每个会话首次写 PCB 前复制游离备份并标记 `[backup]`，且拒绝修改备份 PCB。

## 0.2.13 - 2026-07-21

- 页面检查新增原生网络标签清单。
- 新增经过白名单校验的网络标签移动与改名操作，用于修复“网络标签没有连接导线或总线”。

## 0.2.10 - 2026-07-20

- 新增器件原生属性读取与修改，支持设置 `Value`、键/值可见性。
- 删除图元操作支持文字图元，避免用自由文字冒充器件属性。

## 0.2.9 - 2026-07-20

- 端口矩形碰撞检查跳过整页 `sheet` 图框。
- EasyEDA BETA BBox 异常延伸到页面原点时，按器件原点、PIN 和端口标签矩形回退。

## 0.2.8 - 2026-07-20

- 修复器件属性 BBox 未按父图元过滤造成的超大边界。
- 握手能力列表新增 `operations.validate`，健康状态可显示扩展版本。

## 0.2.7 - 2026-07-20

- 新增只读批量操作预检 RPC。
- 新增端口与导线组合写入：创建后复核真实端口矩形，冲突或失败时执行补偿删除。

## 0.2.6 - 2026-07-20

- 页面检查新增器件本体与可见属性文字的联合 BBox。
- 引脚检查新增电气类型和旋转角度，供端口方向判断与布局使用。

## 0.2.5 - 2026-07-20

- 新增批量器件变换操作，支持移动、旋转和镜像普通器件。
- 页面检查结果新增器件镜像状态。
- 变换结果包含引脚变换前后坐标，且明确报告不会自动修改导线。

## 0.2.4 - 2026-07-20

- 新增批量设置和取消器件引脚原生非连接标识的白名单操作。
- 页面检查结果增加引脚 `noConnected` 状态。
- 写入前校验器件类型、引脚号、重复引脚号和布尔状态，避免无效修改。

## 0.2.3 - 2026-07-20

- 新增“设置 MCP 端口”菜单，可固定连接任意 `1–65535` 端口。
- 端口配置持久化保存，修改后立即断开旧连接并按新端口重连。
- 输入 `0` 可恢复默认的 `49620–49629` 自动扫描模式。

## 0.2.2 - 2026-07-20

- 新增器件与导线成组平移操作。
- 导线平移会保留原有折线结构，将全部端点和拐点应用相同偏移量。
- 只移动调用方明确提供的器件和导线 ID，避免自动选择造成意外断线。

## 0.2.1 - 2026-07-20

- 图页列表改为读取当前工程中的全部原理图，不再要求先打开图页。
- 新增既有普通器件的绝对坐标移动操作。
- 操作校验改为使用工程级图页列表。

## 0.2.0 - 2026-07-20

- 扩展更名为“果子狸MCP服务”，内部唯一名称改为 `guozili-mcp-service`。
- 新增原创 1:1 果子狸电路图标。
- 补齐仓库、分类、主页、问题反馈等扩展市场元数据。
- 将 README、CHANGELOG、LICENSE 和图标加入 `.eext` 安装包。
- 更新菜单、连接提示和状态悬浮框中的产品名称。
- 保留白名单 RPC、连接状态悬浮框、会话首次写入自动备份及原理图操作能力。

## 0.1.7 - 2026-07-20

- 新增原生网络标识创建能力。
- 新增按 PIN 方向创建端口和导线的布局支持。
- 优化常用写操作的 MCP 封装。
